# EnvForge Delivery Governance

`delivery/` contains phase charters, execution prompts, evidence, closure reports,
and handoff manifests. It is delivery evidence, not a second product source of
truth. Normative product and architecture definitions remain under `docs/`.

Each phase follows `EF-DELIVERY-CONTRACT-001@1.1`, records its entry gate, keeps
current implementation guides informative, and ends with a closure report plus a
machine-readable handoff manifest. Historical evidence belongs under
`delivery/history/`; generated outputs belong under `artifacts/generated/`.

Preparation is indexed at `delivery/preparation/evidence/index.md`.
